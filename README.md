# ☕ HALO Coffee Co.

iridescent coffee shop site w/ a drag-to-spin 3D frappuccino, real menu pics n a popup cart 🛒

## Features
* 3D blue frappuccino u can drag + spin 🌀
* every menu item has a real pic on top
* popup cart w/ qty +/- and live total
* payment picker (card/upi/paypal/cash) — just for show, not real 💳
* fully responsive 📱

## Tech
* HTML
* CSS
* JS

(all vanilla, no frameworks)

## Run it
1. clone the repo
2. open `index.html` in ur browser
3. done ✅

## Note
cart + checkout is cosmetic only, nothing actually charges u 💀
